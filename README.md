# NexCart - Modern E-Commerce Web App

A modern, responsive e-commerce application built with React 19, TypeScript, Vite, and Tailwind CSS.

## 🚀 Features
- **Product Catalog**: Live integration with DummyJSON API showcasing products with categories, ratings, and discounts.
- **Search & Filters**: Real-time product search, category filtering, and sorting (price, rating).
- **Interactive Shopping**: Slide-over cart drawer with free shipping progress bar, quantity controls, and order summary.
- **Authentication**: Responsive login and registration pages with credential validation and mock user support.
- **Theme & Design**: Sleek dark slate aesthetic with Plus Jakarta Sans typography, frosted glassmorphism, and micro-animations.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Routing**: React Router DOM v7

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
